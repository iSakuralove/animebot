# 0008. 模糊匹配只对中文名，scorer 用 WRatio

状态: 已采纳
日期: 2026-09-05

## 背景

用户会打错字：`咒术回站`、`白色相薄2`、`无值英雄`。LIKE 子串匹配对错字完全无效，
需要模糊匹配兜底。

两个要定的参数：**喂什么进去**（标题串还是全部别名）、**用哪个 scorer**。

## 决策

- 只对 `title_cn` 做模糊匹配，不用拼接了英文名和别名的 `search_blob`
- scorer 用 `rapidfuzz.fuzz.WRatio`
- 阈值 `fuzzy_min_score=55`，模糊得分乘 4 后仍低于任何子串匹配层级

## 理由

### 长串会让 WRatio 跑偏

第一版喂的是 `title_cn + title_en + aliases` 拼接串（`search_blob`），
长度经常 80+ 字符。结果：

```
查询 '无值英雄'
  排第一: 英雄时代        ← 错的
```

因为 WRatio 对长度差异有惩罚，`无值英雄`(4字) 对
`无职英雄 ～技能什么的毫无用处～ mushoku no eiyuu...`(80+字) 的得分被压低，
反而被短标题 `英雄时代` 超过。

改成只喂 `title_cn` 后：

```
查询 '无值英雄'
  1. 无职英雄 ～技能什么的毫无用处～   ← 对了
  2. 英雄王，为了穷尽武道而转生～...
```

英文名靠 LIKE 覆盖就够了 —— 只有 113/1639（6.9%）的帖子有英文名，
「模糊搜英文名」是臆想需求。

### 五种 scorer 实测对比

对 1639 个真实标题，每个查询取前 3：

| 查询 | WRatio | partial_ratio | token_set_ratio | ratio / QRatio |
|---|---|---|---|---|
| `无值英雄` | **无职英雄(68)** | **无职英雄(75)** | 英雄时代(50) ✗ | 英雄时代(50) ✗ |
| `无职英雄` | **无职英雄(90)** | **无职英雄(100)** | **无职英雄(100)** | 英雄时代(50) ✗ |
| `咒术回站` | **咒术回战(75)** | **咒术回战(86)** | **咒术回战(75)** | **咒术回战(75)** |
| `鬼灭` | **鬼灭之刃(90)** | **鬼灭之刃(100)** | **鬼灭之刃(67)** | **鬼灭之刃(67)** |
| `白色相薄2` | **白色相簿2(80)** | 白色相簿(86) ✗ | **白色相簿2(80)** | **白色相簿2(80)** |
| `紫罗兰永恒花圆` | **京紫(83)** | **京紫(92)** | **京紫(67)** | **京紫(67)** |

**只有 WRatio 在全部 6 个测例上把正确答案排第一。**

`partial_ratio` 在 `白色相薄2` 上把 `白色相簿`（不带 2）排到了
`白色相簿2` 前面 —— 因为子串匹配对它来说更"完整"。这正好是用户最不想要的：
明确打了 2 却给不带 2 的。

`ratio` / `QRatio` 在 `无值英雄` 和 `无职英雄` 上都跑偏。

### 模糊得分必须永远低于子串匹配

打分层级（[service.py](../../src/animebot/search/service.py)）：

```
_EXACT  = 1000    标题完全相等
_PREFIX =  900    标题以关键词开头
_TITLE  =  800    标题包含关键词
_ALIAS  =  700    别名/英文名包含
_BODY   =  500    正文包含
fuzzy   = score × 4，上限 400
```

WRatio 最高 100，乘 4 = 400，仍低于 `_BODY`。所以任何真实的子串匹配都排在
模糊结果之前。这是刻意的：`咒术回战` 明确存在时，不该有个模糊命中插到它前面。

而且模糊匹配**只在完全没有子串命中时才触发** —— 它是兜底，不是并行的一路召回。

## 代价

**中文名以外的错字搜不到。** 打错英文名（`Mushoko` → `Mushoku`）不会被纠正。
可接受：英文名覆盖率只有 6.9%，且用户几乎不用英文搜。

**模糊匹配要拉全表标题。** `all_titles()` 是全表 SELECT，1639 行 ~10ms。
数据量涨到 5 万时这一步会变成 300ms —— 那时候该加一层标题缓存，
或者用 `rapidfuzz.process.cdist` 的批量模式。触发条件很明确，不必现在做。

**阈值 55 是拍的。** 实测里正确答案的得分都在 68 以上，55 留了余量。太低会引入
噪音（`英雄时代` 对 `无值英雄` 得 50），太高会漏。这个数字进了配置
（`ANIMEBOT_FUZZY_MIN_SCORE`），可以按实际反馈调。
