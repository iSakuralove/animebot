# 漫画检索 `/c`：数据实测与交互设计

决策和理由在 [ADR-0013](../ADR/0013-multi-channel-one-library.md)，这里记的是
「漫画频道的数据长什么样」和「/c 用起来是什么样」—— 改交互之前先看这份。

## 数据长什么样（2026-10-24 导出实测）

频道：ACG Library 二次元图书馆，`id=1659887654`，`public_channel`，导出里**没有
username**。2023-01 到 2026-10。

```
消息 1257  →  帖子 938（ok 896 / partial 42 / failed 0）
              文件 271（zip 227 / rar 38 / 7z 6）
              公告闲聊 + 音乐抓包帖 41、无正文 278（文件、贴纸、媒体组）
```

内容：漫画为主（`#漫画` 662），也有轻小说（`#轻小说` 48）。早期的 ACG 音乐抓包帖
（`🔍ACG音乐2021年11月抓包`）没有任何字段，解析器判 SKIPPED —— 它们不是漫画。

### 三代模板

| 时期 | 模板 | 资源在哪 |
|---|---|---|
| 2023 | `中文名/册数/作者/出版社/连载杂志/别名/评分/在线观看/引索/标签/故事简介` | **整卷文件紧跟着发在频道里** |
| 2024~2025 | 首行标题 + `评分/类型/别名/话数/发售日/标签` + `STORY:` | 帖子评论区 |
| 2025~2026 | `中文名/别名/作者/出版社/价格/发售日/页数/ISBN/版本/标签` + `简介` + `链接: Bangumi` + 「资源请在评论区拿」 | 帖子评论区（797 帖写了这句） |

阅读），不算下载 —— 动漫列表只展示 DIRECT 组，所以不受影响。

### 文件归属

271 个文件全部紧跟在某个资料帖后面（同一批上传，中间不夹别的帖子）：

```
#99  进击的巨人          ← 资料帖
#100 [諫山創][進擊的巨人(第8集)][東立電子版].zip
#101 [諫山創][進擊的巨人(第7集)][東立電子版].zip
...  共 55 个，10.8GB
```

规则「文件属于 message_id 不大于它的、最近的那个有效帖子」在全部 271 个文件上
零孤儿、文件名与标题逐个对得上。90 个帖子有文件，最多的是范马刃牙（38 个，21GB）。

## 交互

### `/c <词>` —— 结果列表

```
📚 进击 · 共 1 部 · 第 1/1 页（1-1）

1. 进击的巨人                                    ← 标题，跳频道原帖，命中词加粗
   諫山創 · 34卷 · 2009–2021 · 📦55个文件 10.8GB  ← 斜体元信息 · 文件（跳第一个文件）
```

```
1. 新网球王子
   许斐刚 · 48卷 · 2009–2026 · 网页 · Bangumi
```

- 元信息顺序：评分 · 作者 · 卷数（没有就话数）· 起止年。缺哪项就不写哪项。
- 链接顺序：📦文件 → 资料页 / 在线看 → 网盘。文件排第一：它是最直接能拿到的资源。
- 每页 8 条，多于一页才有翻页行 `⏮ ◀ 2/6 ▶ ⏭`，翻页编辑原消息。
- 禁用链接预览：一行可能有三四个链接，不禁的话 Telegram 抓第一个弹大卡片。

### 宽松模式与「名字相近」

`/c` 是漫画唯一的入口，所以走宽松模式：标题（中文名 + 别名）子串命中优先，零命中
才 fuzzy 纠错。纠错结果在列表头标明：

```
📚 进击巨人 · 共 1 部 · 第 1/1 页（1-1）
没有标题包含这个词，下面是名字相近的：
```

### `/c` 不带词 —— 落地页

```
📚 漫画检索 · 共 938 部

/c 进击的巨人   搜标题：中文名、别名、日文原名都算
/c #百合 #校园  标签交集
/c #恋爱 青春   标签 + 关键词

打错字也能找到名字相近的。点标题跳到频道原帖，资源在帖子评论区；
带 📦 的在频道里直接有整卷文件（共 271 个）。

或者点个标签逛逛：
[#恋爱 119] [#已完结 117] [#漫画系列 113]
[#BL 79]    [#搞笑 76]    [#BLコミック 74]
...
```

标签按钮就是第 0 页的 `#标签` 查询（`c:0:l:#恋爱`），点了把落地页就地编辑成结果
列表。覆盖超过一半帖子的标签不放（`#漫画` 659/938 —— 它什么也筛不掉），按占比判，
不按名字判。

### 回调前缀

| 前缀 | 用途 |
|---|---|
| `c:<page>:<mode>:<query>` | 翻页 / 标签按钮，查询词内联 |
| `ct:<page>:<mode>:<token>` | 查询词超过 64 字节时走 QueryStore |
| `cx` | 占位按钮（页码、到边界） |

动漫的 `s:` / `t:` / `x` 原样不动 —— 聊天记录里的旧按钮还在被点。

## 频道切换：动漫结果 ⇄ 漫画结果

默认搜索（私聊直接发字、`/s`）仍然只出动漫结果 —— 换频道是用户的主动行为，
不替用户猜。主动切换的入口是结果页键盘上的一个按钮：

```
[📚 漫画]            ← 切换行，永远在最上面一行
[⏮ ◀ 2/6 ▶ ⏭]      ← 翻页行，多于一页才有
```

- 动漫结果页是 `📚 漫画`，漫画结果页对称地是 `🎬 动漫`（否则切过去就回不来了）。
- **实现上「切换」不是一个新概念**：它就是用对方频道的前缀、同一查询词、宽松模式
  编码的「第 0 页」翻页按钮（`c:0:l:<词>` / `s:0:l:<词>`）。点击后由对方模块已有的
  `on_page` 接住（路由本来就按前缀分流），重查 + `safe_edit` 原地换掉整条消息。
  长查询词自动走对方的 token 路径。没有新的 callback 格式、没有新处理器。
- **空结果和单页结果也显示切换行**：空结果正是「这个频道没有、去那边试试」最
  有用的时刻；单页结果没有翻页行，但切换行独立存在。
- 多页时翻页行仍然是最后一行 —— 按钮位置不跳（见 search.md 的老约束）。
- **对方模块没加载就不显示**（按 `settings.features` 判断）：点了没人接的
  callback，客户端会一直转圈。
- `/check` 详情和 `/c` 落地页不加：前者是单帖详情，后者没有查询词。
- 带标签的查询词切换过去大概率是空（`#漫改` 在漫画频道不存在）—— 空结果页上有
  返回按钮，不需要特判。

## 明确不做

| 不做 | 理由 |
|---|---|
| bot 内的详情页 | 原帖有封面、排版，2024 年后资源在评论区，只有跳过去才拿得到。和动漫删掉序号详情是同一个结论 |
| 把文件 copyMessage 给用户 | 资源是频道成员的福利；转发等于对非成员分发，还要求 bot 是频道管理员。给跳到第一个文件的深链 |
| 私聊纯文本也搜漫画 | 纯文本是动漫搜索的入口，两个频道混搜就是串台。要漫画就 `/c` |
| 跨频道一起搜 | 同上。结果行的元信息两边完全不同，混在一个列表里没法排版 |
| 评论区资源 | 评论在讨论群里，频道导出不含评论，bot 也看不到 |
